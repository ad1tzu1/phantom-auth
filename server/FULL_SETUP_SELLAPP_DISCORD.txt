================================================================================
Ph3ntom — FULL FLOW (sell.app → Discord → Loader)
================================================================================

USER FLOW
---------
1. Customer pays on ph3ntom.sell.app (e.g. 1 Month)
2. sell.app webhook hits your API → license key is created
3. Customer is sent to:  https://YOUR-API.onrender.com/license?order=ORDER_ID
   and sees the key (copy button)
4. Customer joins Discord → channel redeem-sub
5. Types:  /redeem key:PH3-MON-XXXX-XXXX-XXXX
6. Bot DMs them the loader download link + instructions
7. Customer runs loader → Register/Login (email+password)
8. Loader opens Verification page → paste same license → Verify
9. Main page → LAUNCH → injects velocity.dll from server


================================================================================
A) FIX GIT PUSH FIRST
================================================================================
See GIT_FIX_PUSH_ERROR.txt
Use:
  git pull origin main --allow-unrelated-histories
  git push -u origin main


================================================================================
B) TURSO (database)
================================================================================
1. https://turso.tech sign up
2. Create database "phantom"
3. Copy Database URL (libsql://...)
4. Create Token → copy


================================================================================
C) RENDER (API host — not your PC)
================================================================================
1. https://render.com → New Web Service → connect repo ad1tzu1/phantom-auth
2. Root Directory: server
3. Build: npm install
4. Start: node server.js
5. Environment variables:

TURSO_DATABASE_URL=libsql://...
TURSO_AUTH_TOKEN=...
PHANTOM_JWT=long-random-secret-here-30chars
PHANTOM_OWNER_EMAIL=your@email.com
PHANTOM_OWNER_PASS=YourStrongPassword
PHANTOM_PORT=8787
PUBLIC_API_URL=https://YOUR-SERVICE.onrender.com
LOADER_DOWNLOAD_URL=https://github.com/ad1tzu1/phantom-auth/releases/download/loader/PhantomLoader.exe
DISCORD_BOT_TOKEN=(from Discord developer portal)
DISCORD_REDEEM_CHANNEL=redeem-sub
SELLAPP_WEBHOOK_SECRET=any-long-random-string
DISCORD_API_SECRET=same-or-another-secret

6. Deploy
7. Test: https://YOUR-SERVICE.onrender.com/api/health
   must show ok:true

8. UptimeRobot → monitor that /api/health every 5 min


================================================================================
D) PUT CHEAT DLL ON SERVER
================================================================================
Locally:
  server/private/velocity.dll
Then:
  git add server/private/velocity.dll
  git commit -m "add dll"
  git push
Render redeploys → health dll:true


================================================================================
E) ADMIN PANEL
================================================================================
https://YOUR-SERVICE.onrender.com/admin
Login with owner email/pass
Generate test keys, revoke users, see dll status


================================================================================
F) DISCORD BOT
================================================================================
1. https://discord.com/developers/applications → New Application
2. Bot → Add Bot → Reset Token → copy → put in DISCORD_BOT_TOKEN on Render
3. OAuth2 → URL Generator → scopes: bot, applications.commands
   permissions: Send Messages, Use Slash Commands
4. Open invite URL → add bot to your server
5. Create channel named: redeem-sub (emoji ok in name)
6. Users MUST allow DMs from server members (Privacy settings)
7. After Render has DISCORD_BOT_TOKEN, bot registers /redeem automatically
8. Test: /redeem key:YOURTESTKEY in that channel


================================================================================
G) SELL.APP
================================================================================
1. Create products: 1 Month, 6 Months, 1 Year
   Product names should include: month / 6 month / year
   (API maps name → plan)

2. Webhook URL:
   https://YOUR-SERVICE.onrender.com/webhooks/sellapp

3. If sell.app supports a shared secret header, set it to SELLAPP_WEBHOOK_SECRET

4. Success / Thank you redirect (IMPORTANT):
   https://YOUR-SERVICE.onrender.com/license?order={ORDER_ID}

   Use sell.app's order id variable in the URL if they offer one
   (name may be {order_id} or similar — check sell.app docs)

5. After payment, customer opens that page and copies the key


================================================================================
H) LOADER DOWNLOAD LINK FOR DISCORD DM
================================================================================
Option 1 — GitHub Release:
  1. Build loader Release x64
  2. GitHub repo → Releases → New release → tag "loader"
  3. Upload PhantomLoader.exe
  4. Copy asset URL into LOADER_DOWNLOAD_URL on Render

Option 2 — any file host private link


================================================================================
I) BUILD LOADER
================================================================================
1. Open loader/PhantomLoaderAuth.vcxproj in Visual Studio
2. Edit loader/src/main.cpp top:

   k_api_host  = L"YOUR-SERVICE.onrender.com";  // no https://
   k_api_https = true;
   k_api_port  = 443;

3. Build Release | x64
4. Upload exe to Releases (step H)
