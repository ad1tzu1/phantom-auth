================================================================================
FIX: error: failed to push some refs to github.com/ad1tzu1/phantom-auth.git
================================================================================

This means GitHub already has a commit your PC does not have
(usually you created the repo WITH a README on the website).

IN PowerShell inside your PhantomAuth folder, run THESE EXACT LINES
one by one:

  git pull origin main --allow-unrelated-histories

If it opens a text editor for a merge message:
  - just close it / save (in nano: Ctrl+O Enter, then Ctrl+X)
  - in vim: type :wq and Enter

Then:

  git push -u origin main

----
If pull complains about conflicts and you are fine OVERWRITING the
GitHub repo with your PC folder (safe if the repo only had README):

  git pull origin main --allow-unrelated-histories
  git push -u origin main

Still stuck? Force push (ONLY if repo is new and empty of important files):

  git push -u origin main --force

After a successful push, open:
  https://github.com/ad1tzu1/phantom-auth
You must see loader/ and server/ folders.

Then message: github done
================================================================================
